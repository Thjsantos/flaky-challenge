Avoiding flaky tests: Playwright + C#

Rule of thumb: never read the page once and hope it is ready. Let Playwright wait for the condition.

1. Methods to use

NeedUse
Element count / visible / hiddenExpect(loc).ToHaveCountAsync(n) · ToBeVisibleAsync() · ToBeHiddenAsync()
Text, attribute, stateToHaveTextAsync · ToContainTextAsync · ToHaveAttributeAsync · ToBeEnabledAsync
Page title and URLExpect(Page).ToHaveTitleAsync(...) · Expect(Page).ToHaveURLAsync(...)
Clicking and typingClickAsync · FillAsync already auto-wait (attached, visible, enabled, stable)
Navigation, network, statePage.WaitForURLAsync · WaitForResponseAsync · loc.WaitForAsync() · WaitForFunctionAsync
New tab / popupPage.RunAndWaitForPopupAsync(...)
Stable locatorsGetByRole · GetByText · GetByLabel · GetByTestId, not long CSS chains
Don't hit external sitesAssert the href instead of opening it, or mock with Context.RouteAsync

Avoid as waits or assertions: Thread.Sleep · Task.Delay · CountAsync() · IsVisibleAsync() · InnerTextAsync() · TitleAsync() · Page.Url right after an action. They read once and return.

2. Example from this project: Shows_all_products

Flaky: fixed sleep, then a one-time read
await Page.GotoAsync("catalogo.html");
Thread.Sleep(800);

var count = await Page
  .Locator("#grid article.card").CountAsync();
Assert.Equal(5, count);
Stable: retrying web-first assertion
await Page.GotoAsync("catalogo.html");

await Expect(Page.Locator("#grid article.card"))
  .ToHaveCountAsync(5);

Why: the catalog loads after a random 0-1500 ms delay. Expect retries until the count matches (5 s default timeout), so it passes as soon as the cards render.

3. Running the tests in the Docker image

# from the repo root, in PowerShell, with Docker Desktop running
# one-time, if scripts are blocked:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

./scripts/run.ps1                                              # one run
./scripts/run.ps1 -Repeat 10                                   # 10 runs + green/red summary
./scripts/run.ps1 -Filter "FullyQualifiedName~ProductList"     # one class
./scripts/run.ps1 -Filter "FullyQualifiedName~Shows_all"       # one test
